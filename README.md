# HealthGuard AI

A beginner-friendly Streamlit multilingual health-information chatbot prototype.

## Requirements
- Python 3.9 or newer
- Internet connection for installing Streamlit

## Run on Windows
1. Extract this ZIP file.
2. Open the extracted `HealthGuard-AI` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

5. Open the local address shown in the terminal (usually http://localhost:8501).

## Current prototype features
- English, Telugu and Hindi interface text
- Basic rule-based responses for a few common questions
- Chat history during the current session

## Important
This is an educational prototype, not a medical device or diagnostic tool.
It does not provide diagnoses, prescribe medicines, or replace a qualified
healthcare professional. For urgent symptoms, seek emergency medical help.
